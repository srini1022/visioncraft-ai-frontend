# VisionCraft AI - Frontend

Frontend application for VisionCraft AI image generation platform.

## Structure

- `index.html` - Main HTML entry point
- `css/` - Stylesheets
  - `style.css` - Main styles
  - `responsive.css` - Responsive design rules
- `js/` - JavaScript modules
  - `script.js` - Main application script
  - `api.js` - API communication
  - `ui.js` - UI management
  - `validation.js` - Input validation
- `assets/` - Static assets
  - `images/` - Image files
  - `icons/` - Icon files
  - `logo/` - Logo files

## Development

Serve this folder using a local web server.

## Features

- Image generation interface
- Job status tracking
- Responsive design
